THE AFTER-HOURS  //  CREDITS
==============================

The After-Hours is an unofficial, modified version of "The Backrooms"
(godot-backrooms), a first-person co-op horror game by MehdiBen2:
    https://github.com/MehdiBen2/godot-backrooms

All original work, design, code and content belong to its author. This project is
not affiliated with or endorsed by them. Changes in this version by OrangeDaCat.

Engine: Godot Engine, https://godotengine.org (MIT licence;
Copyright (c) Juan Linietsky, Ariel Manzur and Godot Engine contributors).

Third-party assets used by the game are credited below, as listed in the
original project's asset credit files.

Textures and models under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/):

- pbr/Ceiling_Drop_*/, pbr/Carpet_Yellow_Green/, pbr/Wallpaper_Yellow_* (ceilings, carpet, wallpapers; were YBR_*)
      "Yasu's Backrooms Material Pack" v1.0 by @mvyasu, CC BY 4.0.
      Scaled from 4096 to 2048 px and regrouped one material a folder; the ceiling materials pair each tile set
